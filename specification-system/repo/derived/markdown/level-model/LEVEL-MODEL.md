- **Dependency_direction:**
  - **decision:** dependency-flows-upward-only
  - **rationale:** Dependencies must flow upward through the Level hierarchy (Level 0 -> Level 1 -> Level 2 -> Level 3). Lower Levels must not depend on higher Levels. This prevents circular authority and ensures foundational stability.

  - **decision:** level-model-is-framework-generic
  - **rationale:** The Level model defines only the format, dependency rules, and completeness criteria for product specifications. Product-specific Level content (operation, effect, execution-record semantics) belongs to a separate future product derived from this framework.
