# Staged implementation plans

Files in this directory are preserved historical, non-normative planning evidence.

The current repository-specification implementation planning entry point is:

```text
docs/implementation/REPOSITORY-SPECIFICATION-IMPLEMENTATION-PLAN.md
```

In particular, these predecessor plans are staged and superseded:

- `REPOSITORY-SPECIFICATION-STAND-UP-PLAN.md`
- `REPOSITORY-IDENTITY-IMPLEMENTATION-PLAN.md`

Their historical substantive content remains available for traceability, but they
do not independently authorize implementation and cannot override accepted GVE
normative JSON.
